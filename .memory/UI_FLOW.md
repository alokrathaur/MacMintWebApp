# UI Flow — MacMint Web App

- **Home Page**:
  - Hero (3D Logo + Download CTA)
  - Interactive Sunburst Demo (Click to drill down into folders)
  - Features Grid (Deep Clean, Uninstaller, Startup Manager)
  - Comparison Table (MacMint vs CleanMyMac vs DaisyDisk)
  - Pricing (Toggle Yearly $14.99 / Lifetime $29.99)
  - FAQ Accordion
  - Footer
- **Subpages**:
  - `/features`: Deep dive into system tools.
  - `/pricing`: Detailed plan benefits.
  - `/download`: Instructions for bypassing Gatekeeper & installing.
  - `/guides`: Mac optimization articles.
  - `/activate`: Enter license token to verify seats.
